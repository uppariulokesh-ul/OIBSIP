# Java Development Internship - Task 2
## Number Guessing Game (OIBSIP)

### Project Overview
A Java GUI-based game developed using Java Swing and AWT where the player guesses a randomly generated number with limited attempts across 3 rounds.

### Features
- User-friendly GUI with real-time feedback
- 3 Rounds with 5 attempts per round
- Dynamic score calculation based on remaining attempts

### How to Run
```bash
javac NumberGuessingGame.java
java NumberGuessingGame
