# Java Development Internship - Task 3
## ATM Interface (OIBSIP)

### Project Overview
A desktop-based ATM Interface built with Java Swing and AWT. Features custom login verification, transaction logging, withdrawals, deposits, and money transfers.

### Features
- Secure PIN authentication (1234)
- Real-time Balance tracking and update
- In-app cash deposit & withdrawal systems
- Fund transfers to custom account IDs
- Comprehensive Transaction History modal

### How to Run
```bash
javac ATMInterface.java
java ATMInterface
