# Java Development Internship - Task 4
## Online Examination System (OIBSIP)

### Project Overview
A desktop-based Online Examination System built using Java Swing and AWT. It features candidate authentication, a dynamic countdown timer, multiple-choice questions (MCQs), auto-submission on timeout, and instant score calculation.

### Features
- User Login Authentication
- 60-second real-time countdown timer
- Multiple-choice questions with option selection tracking
- Automatic submission on time expiration
- Final score report calculation (out of 100)

### How to Run
```bash
javac OnlineExamination.java
java OnlineExamination
