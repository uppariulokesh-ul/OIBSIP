# Java Development Internship - Task 2
## Number Guessing Game (OIBSIP)

### Project Overview
A Java GUI-based game where the user tries to guess a randomly generated number within 3 rounds, with a limited number of attempts per round.

### Features
- **Interactive GUI**: Created using Java Swing & AWT.
- **Multiple Rounds**: Total of 3 rounds, each with a different target number.
- **Attempt Limits**: Maximum of 5 attempts allowed per round.
- **Feedback & Scoring**: Real-time feedback ("Too High" or "Too Low") and point calculations.

### How to Run
```bash
javac NumberGuessingGame.java
java NumberGuessingGame
